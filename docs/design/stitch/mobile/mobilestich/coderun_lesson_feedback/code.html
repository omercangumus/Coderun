How do you correctly initialize an empty dictionary?

cancel my_dict = []
Your Answer

error Why it is wrong

Square brackets [] are used to initialize empty Lists in Python, not dictionaries. Using them creates an ordered sequence, which lacks the key-value structure of a dictionary.

lightbulb Quick Hint

Dictionaries need to be able to hold key-value pairs. Think about the curly braces {} or the explicit dict() constructor.
